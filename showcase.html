Website · Business Platform
BDOS — Business Development Operating System
FrontendHTML · CSS · JavaScript (25 modules)
BackendPython · FastAPI · Uvicorn
DatabaseAWS PostgreSQL · psycopg2 pooling
AuthJWT · bcrypt password hashing
Contact CaptureScan Card (OCR) · Manual · NFC tap
Tender IntakeUpload RFP → auto-detect title, agency & reference
AIGemini vision → Claude vision fallback → on-device OCR
DeploymentDocker · GitHub Actions → EC2
DescriptionA full business-development operating system for Geospatial AI, replacing scattered spreadsheets with one hub. Its standout feature is contact capture: snap or upload a business card and the AI reads it — Gemini vision first, falling back to Claude vision and then on-device OCR — then auto-fills name, company, title, email, mobile, office phone, website and address for review before saving, even fetching the company logo from the card crop or the company website. An NFC mode adds a contact by tapping a supported card on an Android phone. CRM tracks leads, contacts and the opportunity pipeline through prospecting → qualification → proposal → negotiation → won. Qualification scores every discovery entry server-side against five criteria (named decision, decision maker, budget, procurement route, urgency) for a 0–10 score, with red flags such as “no decision maker” or “send proposal first”. Tender Hub starts by ingesting the RFP itself — upload the PDF and the title, agency and reference number are detected for you — then carries the tender through set team, an AI-generated to-do list, strategy-to-win and AI-assisted proposal drafting into the bidbook. Plus quotations, budget, after-action reviews, a BD calendar, a daily news signal feed across Malaysian business media, a team scoreboard, live reporting with PDF/CSV export, NFC business-card capture and an admin console. Backed by a 14-table PostgreSQL schema and a 34-route FastAPI service shaped to mirror the previous Firebase API, so the front end migrated with a one-line base-URL change.

Website · Soil Survey
UZMATerraVision — Soil Correlation Platform
FrameworkNext.js · React
AccessAuthenticated survey officers
Project1/2026 Pontian, Johor — peat management
ModulesDashboard · Pedons · Pedon Map · Reports · Reference
DescriptionA field platform for soil correlation surveys. Officers register each pedon — a soil profile — then work it through a guided flow: general details, a Munsell colour reading taken from a photo, and lab results, with progress tracked per profile as pending or done. A pedon map plots every profile on satellite imagery, and a reference module holds the vocabularies the survey is scored against: oil palm suitability classes, pH reaction bands, peat categories by loss on ignition, land use, drainage, parent material, topography, substratum and horizons. The API applies those same rules server-side on save, so classification stays consistent.

LanguageHTML · CSS · JavaScript

DescriptionAn interactive land use and building footprint dashboard covering 15,844 mapped features across Seremban, Negeri Sembilan, served from proprietary UzmaSat-1 raster tiles.
